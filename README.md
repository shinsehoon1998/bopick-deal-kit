# 보픽플래너 협상 키트

보픽플래너(주식회사 마셈블)의 대외 협상을 돕는 Claude용 지식 묶음입니다. 다루는 협상은 세 가지입니다.

- 다른 GA 조직 도입 영업
- 투자 유치
- 인플루언서 협업

**기준일: 2026-10-28.** 이 날짜 뒤의 변경은 대표가 이 저장소를 고쳐야 반영됩니다.

> ⚠️ 이 저장소는 **공개**입니다.
> - 상대방(GA·투자사·크리에이터)이 읽어도 되는 내용만 들어 있습니다.
> - 운영 실적·진행 중 딜·대표 관련 대응 문구는 **대표에게 따로 받은 내부전용 링크**에 있습니다.
> - 내부전용 파일은 이 저장소에 올리지 마세요.

---

## 1. claude.ai(웹·앱)에서 쓰기 — 추천

1. claude.ai 왼쪽 메뉴에서 **프로젝트 → 새 프로젝트**를 만듭니다. 이름 예: `보픽 협상`
2. **프로젝트 지침(Instructions)** 에 [`CLAUDE.md`](CLAUDE.md) 내용을 전부 복사해 붙여 넣습니다.
3. **프로젝트 지식(Knowledge)** 에 파일을 넣습니다. 둘 중 편한 방법으로 하세요.
   - **GitHub 연결**: `+` → `GitHub` → 이 저장소 주소를 붙여 넣고 → `.md` 파일을 모두 선택합니다.
   - **ZIP 업로드**: 이 페이지 위쪽 초록색 `Code` 버튼 → `Download ZIP` → 압축을 풉니다. 그다음 `.md` 파일(폴더 `playbooks/` 포함)을 끌어다 놓습니다.
4. 대표에게 받은 **내부전용 파일**도 같은 프로젝트 지식에 올립니다.
5. 대화를 시작합니다. 아래 '이렇게 물어보세요'를 참고하세요.

## 2. Claude Code에서 쓰기

```bash
git clone https://github.com/shinsehoon1998/bopick-deal-kit.git
cd bopick-deal-kit
mkdir -p internal          # 내부전용 파일은 여기에 둡니다 (.gitignore 로 올라가지 않음)
claude
```

`CLAUDE.md` 는 자동으로 읽힙니다. 새 판은 `git pull` 로 받습니다.

## 3. 파일 지도

| 파일 | 내용 | 언제 |
|---|---|---|
| `CLAUDE.md` | Claude가 지킬 역할·철칙·권한·형식 | 항상(지침) |
| `00_한눈에.md` | 회사·제품·숫자·가격을 한 장으로 | 항상 먼저 |
| `01_제품_기능.md` | 기능 전체와 상태(운영 중/준비 중/없음) | 기능 질문 |
| `02_가격_정책.md` | 요금제·크레딧·단가·환불 | 가격 질문 |
| `03_숫자원장.md` | 대외에 써도 되는 숫자 문장과 쓰면 안 되는 표현 | 숫자 쓸 때마다 |
| `04_경쟁_시장.md` | 시장 규모·우리 위치 | 비교 질문 |
| `05_준법_금지선.md` | 보험·개인정보·광고 규제상 하면 안 되는 것 | 초안 검토 |
| `playbooks/GA_엔터프라이즈_영업.md` | GA 조직 도입 협상 | GA 영업 |
| `playbooks/투자_제안.md` | 투자 유치 협상 | 투자 |
| `playbooks/인플루언서_협업.md` | 크리에이터 협업 협상 | 인플루언서 |
